Passos previs a la Install Party

Prepara el teu equip abans del gran esdeveniment.

Per a aprofitar al màxim la Install Party de setembre i assegurar que la instal·lació sigui ràpida i fluida, és imprescindible que hagis completat aquests 4 passos previs abans d'assistir:

1. Conèixer Debian

Debian és una de les distribucions Linux més antigues, estables i respectades. És la base sobre la qual es construeixen molts altres sistemes (com Ubuntu).

  • Tasca: mira aquest short explicatiu sobre Debian.
  • Descarregar ISO de Debian 13.6.0 (amd64)

2. Conèixer Ubuntu

Ubuntu és la distribució Linux més popular del món, molt recomanada per a principiants pel seu gran suport comunitari i facilitat d'ús.

  • Tasca: mira aquest short explicatiu sobre Ubuntu.
  • Descarregar ISO de Ubuntu 26.04 LTS (amd64)
  • Descarregar ISO de Ubuntu 26.04 LTS (arm64)

3. Conèixer Linux Mint

Linux Mint és coneguda per oferir una interfície molt familiar i còmoda per a usuaris que venen de Windows, amb un rendiment excel·lent.

  • Tasca: mira aquest short explicatiu sobre Linux Mint i els seus diferents entorns, nosaltres recomanem Cinnamon.
  • Descarregar ISO de Linux Mint 22.3 Cinnamon (64bit)

4. Instalar la ISO en un Pendrive amb Rufus

Per a poder instal·lar el sistema operatiu al teu portàtil, necessitem cremar la imatge .iso de la distribució triada en un memòria USB arrancable.

  • USUARIS DE WINDOWS: mira aquest tutorial pas a pas de com utilitzar l'eina lliure Rufus per a crear un USB d'arrencada (bootejable) desde Windows 11.
  • USUARIS DE MAC OS: mira aquest tutorial pas a pas de com utilitzar l'eina lliure balenaEtcher per a crear un USB d'arrencada (bootejable).
  • Requisit indispensable: Porta el teu pendrive USB ja preparat el dia de l'esdeveniment. Si no, haurás de comprar un el mateix dia de l'esdeveniment.

Ara que has preparat el teu pendrive inscriu-te a la Install Party
