Passos previs a la Install Party

Prepara el teu equip abans del gran esdeveniment.

Per a aprofitar al màxim la Install Party de setembre i assegurar que la instal·lació sigui ràpida i fluida, és imprescindible que hagis completat aquests 3 passos previs abans d'assistir-hi:

1. Conèixer Debian

Debian és una de les distribucions Linux més antigues, estables i respectades. És la base sobre la qual es construeixen molts altres sistemes (com ara Ubuntu).

  • Tasca: mira aquest vídeo breu (short) explicatiu sobre Debian.
  • Descarregar la ISO de Debian 13.6.0 (amd64)

2. Conèixer Linux Mint

Linux Mint és coneguda per oferir una interfície molt familiar i còmoda per a usuaris que venen de Windows, amb un rendiment excel·lent.

  • Tasca: mira aquest vídeo breu (short) explicatiu sobre Linux Mint i els seus diferents entorns; nosaltres recomanem Cinnamon.
  • Descarregar la ISO de Linux Mint 22.3 Cinnamon (64 bits), recomanem el "mirrors" fets a Espanya

3. Instal·lar la ISO en un llapis USB (Pendrive) amb Rufus

Per a poder instal·lar el sistema operatiu al teu portàtil, necessitem enregistrar la imatge .iso de la distribució triada en una memòria USB d'arrencada.

  • USUARIS DE WINDOWS: mira aquest tutorial pas a pas de com utilitzar l'eina lliure Rufus per a crear un USB d'arrencada (bootejable) des de Windows 11.
  • USUARIS DE MAC OS: mira aquest tutorial pas a pas de com utilitzar l'eina lliure balenaEtcher per a crear un USB d'arrencada (bootejable).
  • Requisit indispensable: porta el teu llapis USB ja preparat el dia de l'esdeveniment. Si no, n'hauràs de comprar un el mateix dia de l'activitat.

Ara que has preparat el teu USB, inscriu-te a la Install Party
